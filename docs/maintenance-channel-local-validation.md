# 人工维护通道本地验证结果

更新时间：2026-09-21

状态：本地可丢弃虚拟机验证通过；尚未在生产环境验证。

## 验证了什么

在一台独立 Ubuntu 22.04 虚拟机中安装 Guardian 和维护资源保护配置，然后分别制造 CPU、内存、磁盘读写、磁盘容量和进程数压力。

每个场景重复检查 20 次：

- 能否进入虚拟机；
- 能否执行只读诊断；
- 能否查看 Docker 容器；
- Guardian 能否完成一次观察。

五类压力下所有检查均成功。详细数字见 [maintenance-channel-local-results.csv](maintenance-channel-local-results.csv)。

## 安装和恢复结果

- Guardian 能以只观察模式启动并报告就绪。
- 虚拟机重启后 Guardian、Docker 和 containerd 能恢复。
- Guardian 可以单独停用和重新启用，不影响 Docker、Beszel 和系统服务。
- 错误配置被拒绝，恢复正确配置后服务继续运行。
- 快照回滚后可以重新安装。
- 日志设置了空间和速率边界。
- 自动动作服务全程关闭，真实动作数为零。

## 这项结果不代表什么

- 不代表生产服务器在任何资源耗尽情况下都能 SSH 登录。
- 不代表已经覆盖真实网络、认证、硬盘故障和根分区完全写满。
- 不替代云控制台、BMC/IPMI 等带外恢复方式。
- 不代表 Guardian 已经可以自动处理生产容器。
